# Demo Project

A simple project to demonstrate MDx Code capabilities.

## Setup

```bash
cd examples/demo_project
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Run Tests

```bash
python -m pytest
```

## Files

- `src/calculator.py` - A simple calculator with intentional bugs
- `src/auth.py` - Authentication module with security issues
- `tests/test_calculator.py` - Tests for calculator
